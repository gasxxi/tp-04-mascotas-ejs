# Trabajo práctico 04

## Descripción
En este trabajo práctico desarrollé una aplicación web con Node.js y Express usando el motor de plantillas EJS para gestionar un sitio de adopción de mascotas. La información inicial se carga de forma asíncrona desde un archivo JSON antes de iniciar el servidor, y luego los registros se administran en un arreglo en memoria. La aplicación produce páginas HTML completas renderizadas del lado del servidor.
